Para confirmar una entrega, a tu cliente le sirve un botón que diga «Cambiar horario». Para entrar a su cuenta sin datos móviles, le sirve más un código por SMS. La elección no empieza en el canal: empieza en lo que la persona necesita hacer y en qué puede usar en ese momento.

CriterioSMS corporativoWhatsApp API
ConectividadLlega sin datos móviles ni wifi, solo con señalEl cliente necesita WhatsApp e internet
ExperienciaTexto breve, con un enlace si hace faltaBotones, imágenes, documentos y conversación

Cuidado con las cifras de apertura

Seguramente has visto presentaciones que prometen «98 % de apertura». Muchas veces mezclan entrega, lectura y recuerdo del mensaje. Con el SMS estándar sabes si se entregó, pero no si se abrió. En WhatsApp puedes ver la lectura cuando está disponible. Y ninguna de las dos señales te dice si la persona entendió el mensaje o hizo lo que esperabas.

Como referencia, en un estudio de Ofcom en el Reino Unido el 65 % de las personas dijo revisar sus SMS apenas llegan. Es una encuesta de otro país: para saber cómo responde tu público en Ecuador, necesitas tus propios datos.

Cuándo usar cada uno

Elige SMS cuando tu cliente puede estar sin datos, cuando parte de tu público no usa WhatsApp o cuando basta un aviso corto. Para códigos de seguridad es el canal más seguro de que llegue.

Elige WhatsApp cuando esperas una respuesta y quieres resolver todo en la misma conversación: confirmar, reprogramar o pedir ayuda sin llamar.

Combina los dos para avisos críticos. Envía primero por WhatsApp y, si después del tiempo que definas no se entregó, manda un SMS corto de respaldo. Si el primero llegó o el cliente ya respondió, cancela el SMS para no duplicar.

En una prueba compara mensajes entregados sobre intentados, tiempo de entrega, costo por resultado y acciones completadas. Si envías códigos, la métrica que importa es cuántas personas completaron la verificación a tiempo. Tenemos los dos canales: SMS corporativo a todas las operadoras y WhatsApp API para empresas.
